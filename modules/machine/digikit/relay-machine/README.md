# Relay

Relay is a stereo live looper for Digitakt II OS 1.17. It records a pattern-length take from MAIN, EXT, or one
track. Adjust the playback position, direction, and feedback from the SRC pages. Use the second SRC page for a
larger waveform.

Relay requires the DigiKit Relay track adapter (`core/relay-track`).
