# RELAY recording pool

Select `core/relay-storage` on DTII 1.17 to reserve 32 MiB immediately below the phrase banks. The extra reservation reduces stock sample capacity from 376 to 344 MiB. The six stock allocator operands have one owner, `core/loop-storage`, which tests for the linked descriptor via `defined(_relay_storage_info)`. Omitting RELAY leaves both phrase bank addresses, the Overloop buffer and stock sample capacity at their existing values.

On the SHARC, `_relay_pool` accepts commands from [dk_relay.inc](../../../../sdk/dsp/contract/dk_relay.inc). One DSP owner calls it serially. Reset once at activation with all readers stopped. The first 64 KiB holds metadata, and 511 reusable pages each contain 16,384 packed stereo PCM16 frames. A page is allocated when first written. The empty pool has 8,372,224 usable frames (174.42 s at 48 kHz). Each track owns a main slot (9–24), two take lanes (25–40 and 41–56), and an undo slot (57–72). The export pin (7) and staged writer (8) are shared. A pin retains an immutable revision even if the source is subsequently cleared.

* BEGIN stages a replacement without touching a destination. R8 is the required length, or zero for an open-ended take. RETARGET checks a new length before the first write. For an overdub, use the original length and fill the workspace with the mixed signal. REWRITE updates an already written frame for subsequent wraps. FINISH_DUB atomically moves the previous main to undo and installs the workspace, checking the lengths match. COMMIT replaces slot R8 with a nonempty staged take. ABORT returns the staging pages.
* APPEND writes one packed frame in R8. For block transfer, ACQUIRE returns the next byte address and R1 writable frames up to the next page or take boundary. Write the PCM there and PUBLISH the count in R8 before acquiring another span. Only published frames can be read. Discard any outstanding pointers on abort/reset.
* READ_SPAN (slot R8, frame R12) returns a byte address and contiguous readable frames in R1. LENGTH queries a slot. SWAP exchanges slots R8 and R12 for take promotion or undo/redo. PIN binds the published take in R8 until UNPIN. CLEAR drops the slot. Readers must finish their span or hold a pin before a slot can be retired. AVAILABLE returns frames in free pages plus the writer's unused tail.

The DSP rig runs the assembled routines. The stock allocator boundary check also accepts `--relay` for a provider-only image built with the extra reservation. See [loop-storage](../loop-storage/README.md).
